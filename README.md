# Mini Message Board

A static and simple message board, it doesnt have multi user feature just one
endpoint.

Utilizes view and routes, the view are implemented with ejs.

From this project, achieved the opportunity to practice created view templates
with ejs as well as implementing routes using express js.

Knowledge acquired from the past three lessons were also mainly focused on these
three concpets and the basics of how express actually works under the hood.
